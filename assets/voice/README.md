# assets/voice — 목소리 참고음성

목소리 하나는 폴더 하나입니다. 폴더 안에 `참고목록.json` 과 그 목록이 가리키는 wav(보통 `default.wav`)가 있어야
목소리 서버(Qwen3-TTS)가 그 목소리로 말할 수 있습니다.

| 폴더 | 목소리 | 성별 | 지금 상태 |
|---|---|---|---|
| `kimbiseo/` | 김비서(여) | 여 | 있음 — 기본목소리 |
| `kimbiseo_m/` | 김비서(남) | 남 | `참고목록.json` + `default.wav` 자리(없으면 대체) |

## 성별 → 목소리

- 사용자 설정(settings.json)에 `목소리.목소리` 가 **없으면** `펫.성별` 로 고릅니다: 여 → `kimbiseo`, 남 → `kimbiseo_m`.
- `목소리.목소리` 가 **있으면** 그 값을 고정으로 보고 자동 연결을 하지 않습니다.
- 고른 목소리의 참고음성이 없으면(폴더·`참고목록.json`·wav 중 하나라도 없음) 기본목소리 `kimbiseo` 로 대체하고
  `목소리 kimbiseo_m 참고음성 없음 → 기본 kimbiseo 사용` 같은 한 줄을 로그와 설정 화면 경고에 남깁니다.
  목소리 서버는 요청마다 `voice` 를 받으므로, 자산이 나중에 들어오면 서버를 다시 켜지 않아도 그 목소리를 씁니다.

## 파일 모양

`참고목록.json`:

```json
{
 "기본": {"wav": "default.wav", "text": "그 wav 에서 실제로 하는 말"}
}
```

- `기본` 은 꼭 있어야 합니다. 감정별 참고음성을 더하려면 `"기쁨"`, `"걱정"` 같은 키를 같은 모양으로 더합니다.
- 목소리 목록과 기본목소리·성별 연결은 `voice/voices.json` 이 정합니다.
