# assets/voice — 목소리 참고음성

목소리 하나는 폴더 하나입니다. 폴더 안에 `참고목록.json` 과 그 목록이 가리키는 wav(보통 `default.wav`)가 있어야
목소리 서버(Qwen3-TTS)가 그 목소리로 말할 수 있습니다.

| 폴더 | 목소리 | 성별 | 만든 방법 |
|---|---|---|---|
| `kimbiseo/` | 김비서(여) — 기본목소리 | 여 | Qwen3-TTS VoiceDesign 합성(사람 녹음 아님) |
| `kimbiseo_m/` | 김비서(남) | 남 | Qwen3-TTS VoiceDesign 합성(사람 녹음 아님) |

두 견본 모두 지시문만으로 합성한 목소리가 중립 문장을 읽은 것이고, ASSETS-LICENSE.md 조건(개인 사용·재배포·AI 학습 금지)을 따릅니다.

## 목소리를 고르는 순서

1. 설정에서 목소리를 **직접 골랐으면**(settings.json 의 `목소리.목소리` = `kimbiseo` 또는 `kimbiseo_m`) 늘 그 목소리입니다.
2. '옷에 맞춤(자동)'(`목소리.목소리` 가 없거나 `auto`)이고 펫이 켜져 있으면 **펫이 지금 입은 옷**으로 고릅니다.
   옷 꾸러미 `pack.json` 의 `voice`(선택) → `voices.json` 의 `옷목소리.옷[옷 id]` → `옷목소리.성별[꾸러미 성별]`.
   옷을 갈아입으면 다음 말부터 그 옷의 목소리로 말합니다(목소리 서버를 다시 켜지 않습니다).
3. 펫이 꺼져 있거나 옷으로 못 고르면 설정의 `펫.성별` 로 고릅니다: 여 → `kimbiseo`, 남 → `kimbiseo_m`.
4. 고른 목소리의 참고음성이 없으면(폴더·`참고목록.json`·wav 중 하나라도 없음) 기본목소리 `kimbiseo` 로 말하고
   `목소리 kimbiseo_m 참고음성 없음 → 기본 kimbiseo 사용` 같은 한 줄을 로그와 설정 화면 경고에 남깁니다.
   목소리 서버가 모르는 이름을 받아도 말을 빼먹지 않고 기본목소리로 말합니다.

`voices.json` 의 대응표:

```json
"옷목소리": {"성별": {"여성": "kimbiseo", "남성": "kimbiseo_m"}, "옷": {"<옷 id>": "<목소리 이름>"}}
```

## 파일 모양

`참고목록.json`:

```json
{
 "기본": {"wav": "default.wav", "text": "그 wav 에서 실제로 하는 말"}
}
```

- `기본` 은 꼭 있어야 합니다. 감정별 참고음성을 더하려면 `"기쁨"`, `"걱정"` 같은 키를 같은 모양으로 더합니다.
- 목소리 목록과 기본목소리·성별·옷 연결은 `voice/voices.json` 이 정합니다.
