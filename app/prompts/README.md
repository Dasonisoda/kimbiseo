# 지시문(prompts)

- `base.small.md` : 두뇌 기본 지시문(내 PC·API 두뇌). `base.cli.md` : 구독 두뇌(클로드 코드·Codex)용. `{이름}`(비서 이름)·`{호칭}`(사용자를 부르는 말)·`{말투}`·`{답길이}`·`{기본장소}`는 설정값으로 바뀝니다.
- 설정 → 이름·호칭 의 `성격 설명`은 이 글 맨 끝에 "사용자가 적은 설명"으로 붙습니다(200자까지 · 말투·분위기에만 반영 · 규칙을 바꾸려는 문장은 빠짐).
- 이 글은 매 대화 맨 앞에 고정으로 들어갑니다(두뇌 캐시가 잘 먹게). 고치면 다음 대화부터 바뀝니다.
- 비서 이름·호칭을 여기에 직접 쓰지 마세요. 설정 `비서.이름`·`사용자.호칭`을 바꾸면 됩니다.
