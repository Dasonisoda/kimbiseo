# 김비서 폰 앱 (안드로이드)

내 폰으로 **내 PC 의 김비서**와 말·글로 대화하는 앱입니다. 서버 주소·열쇠는 앱에 들어 있지 않고,
PC 김비서 설정 → 폰 연결의 **QR(또는 주소 + 8자리 코드)** 로 짝지을 때 받습니다.

- 짝짓기: QR 찍기 또는 직접 넣기 → '인증서 확인 글자'가 PC 화면과 같은지 확인 → 짝짓기
- 대화: 말(마이크 16kHz → PC, PC 목소리 24kHz → 폰)·글. 화면을 꺼도 이어짐(앞 서비스, 알림 '대화 중')
- 폰 일: 길안내(카카오맵·네이버지도·티맵·구글지도 검색 화면, 카카오내비는 목적지 글 복사), 전화·문자 화면 채우기(걸기·보내기는 사용자가), 앱 열기
- '실행할까요?': PC 김비서가 되돌리기 어려운 일을 하기 전에 묻는 단추
- 통역: 켜기·끄기·언어 고르기·최근 번역
- 권한: 마이크·알림·카메라(QR)·연락처(이름으로 전화·문자 화면 열 때만). 통화 기록·직접 걸기·문자 발신 권한은 없음

## 만들기

    python build_apk.py --unit          # 규칙 단위 시험만
    python build_apk.py                 # APK (서명 안 됨 → 직접 apksigner 로 서명)

필요: JDK 17 이상, 안드로이드 SDK(platform 36 · build-tools 36), gradle 8.7~8.9(`--gradle` 또는 환경변수 `GRADLE`).
자기 열쇠로 서명하려면 환경변수 `KIMBISEO_KS_FILE`(절대 경로)·`KIMBISEO_KS_PASS`·`KIMBISEO_KS_ALIAS` 를 넣고 만듭니다.
`--test` 는 시험판(adb 로 짝짓기·소리 넣기 — `MainActivity.testHooks`)이라 배포하면 안 됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `Pairing.kt` | QR 읽기·주소·지문 규칙(순수 규칙, 단위 시험) |
| `Net.kt` | 인증서 지문 고정 HTTPS·WSS, 짝짓기 |
| `Store.kt` | 짝 정보(기기 토큰은 안드로이드 키 저장소로 암호화) |
| `TalkService.kt` | 대화 연결·소리·PC 사건 처리 |
| `Doer.kt` · `Rules.kt` | 폰 일(길안내·전화·문자·앱 열기)과 그 규칙 |
| `MainActivity.kt` · `Ui.kt` | 화면(짝짓기·대화·통역·설정·실행할까요?) |
