# 김비서 (KimBiseo)

내 PC 안에서 돌아가는 **말로 부르는 비서**와 **바탕화면 캐릭터 펫**입니다.
"김비서" 하고 부르거나 창에 글을 쓰면 대답하고, 바탕화면의 펫이 말에 맞춰 입을 움직이고 표정·동작을 합니다.

이 프로젝트는 하이라이프PC 가 만들었습니다.

## 무엇을 하나요

- **대화**: 말로 묻고 말로 듣습니다. 날씨·검색·가격 조사·계산·프로그램 열기·기억하기·메모 적기 같은 기본 도구가 들어 있습니다.
  "RTX 5090 가격 검색해서 메모장에 정리해 줘"처럼 여러 단계 부탁도 차례로 합니다. 메모는 김비서가 직접 띄우는 **김비서 메모** 창에만 적고
  (윈도우 메모장은 저절로 켜지 않음), Ctrl+S·저장 단추로 `문서\김비서 메모\` 에 저장합니다.
- **두뇌**: 이 PC 에 클로드 코드·Codex(ChatGPT)가 본인 계정으로 로그인돼 있으면 그 구독을 그대로 씁니다(김비서가 그 프로그램을 직접 부름 — 계정·토큰은 김비서가 보지 않음). 없으면 내 PC 에서 도는 Gemma 4 무검열 판(보통 E4B · 가벼운 E2B 중 고름, llama.cpp, 원 배포처에서 직접 받음). 설정에서 내 로컬 AI 주소(OpenAI 호환)·API 열쇠(GPT·클로드)로도 바꿀 수 있습니다.
- **귀·목소리**: 받아쓰기는 whisper, 목소리는 Qwen3-TTS 김비서 목소리(그래픽 메모리 6GB 미만·모자랄 때는 윈도우 기본 음성). 김비서(여)·김비서(남) 두 목소리가 들어 있고, 펫이 입은 옷에 맞춰 저절로 바뀝니다(설정에서 직접 고를 수도 있음).
- **펫**: 바탕화면 캐릭터 — 김비서(여)·김비서(남). 옷(꾸러미)은 처음 화면에서 동의하면 고른 캐릭터의 옷을 받고, 다른 옷은 펫 메뉴 **옷 더 받기** 에서 원하는 것만 골라 받습니다(옷 목록 = [kimbiseo-outfits](https://github.com/sinhs0301-prog/kimbiseo-outfits)).
- **내 자료는 내 PC 에**: 모든 프로그램은 이 PC 안(127.0.0.1)에서만 듣습니다. 설정·대화 기억·열쇠는 이 PC 에만 저장합니다.
  바깥 두뇌(GPT·클로드 등)를 고르면 대화 글만 그 회사로 갑니다.

## 권장 사양

| | 최소 | 권장 |
|---|---|---|
| 운영체제 | 윈도우 10/11 64비트 | 윈도우 11 |
| 램 | 16GB | 32GB |
| 그래픽카드 | 없어도 됨(두뇌는 바깥 AI, 목소리는 윈도우 음성) | 엔비디아 그래픽 메모리 12GB 이상 |
| 디스크 | 약 10GB(그래픽카드 없음) | 약 25GB |

엔비디아 그래픽 메모리 6GB 이상이면 김비서 목소리(Qwen3-TTS)를, 그보다 작거나 없으면 윈도우 기본 음성을 씁니다. 김비서 목소리는 켤 때 그래픽 메모리가 3.3GB 이상 남아 있어야 그래픽카드로 켜고, 그보다 적으면(두뇌·다른 프로그램이 쓰는 중) 끊기는 대신 윈도우 음성으로 시작합니다. 쓰는 중에 그래픽 메모리가 모자라면 목소리가 끊기지 않고 윈도우 음성으로 저절로 바뀝니다.
마이크와 스피커(또는 헤드셋)가 필요합니다.

## 설치

1. [Releases](https://github.com/sinhs0301-prog/kimbiseo/releases/latest) 에서 `KimBiseo-setup-<판>.zip` 을 받습니다.
2. zip 을 오른쪽 클릭 → 속성 → '차단 해제' 체크(있을 때만) → 압축 풀기.
3. 풀린 폴더의 `설치.bat` 을 두 번 누릅니다. 파란 경고창이 뜨면 '추가 정보' → '실행'.
4. 설치 창에서 '설치' 를 누르면 끝까지 저절로 합니다(빠른 인터넷에서 15~25분).
5. '김비서 켜기' 또는 바탕화면 '김비서' 아이콘. 처음 화면이 이름·호칭·두뇌·목소리·마이크를 차례로 물어봅니다.

파이썬·부품·모델은 설치할 때 공식 배포처(python.org · PyPI · PyTorch · GitHub · 허깅페이스)에서 내 PC 가 직접 받고,
받은 파일마다 sha256 을 확인합니다. 자세한 안내는 zip 안의 `설치방법.txt` 에 있습니다.

받다가 끊기면 받은 만큼에서 이어 받고, 안 되면 다른 방식(윈도우 내려받기)으로 다시 받습니다. '펫' 단계만 못 받았을 때는
설치를 끝내고 김비서(대화)부터 쓸 수 있으며, 펫은 설치 창의 '펫 다시 받기'·'직접 넣기'나 김비서 설정 → 펫 에서 나중에 넣을 수 있습니다.
설치 창에는 지난 시간과 지금 하는 일(받는 파일·받은 양·남은 시간)이 보이고, 3분 넘게 진전이 없으면 알려 줍니다.

지우기: 시작 메뉴 '김비서 제거' 또는 윈도우 설정 → 앱 → 김비서 → 제거(대화 기억·설정을 남길지 물어봅니다).

## 업데이트

- 김비서를 켤 때(하루 한 번까지) 새 판이 있는지 봅니다. 설정 → 정보 → '업데이트 확인' 으로 바로 볼 수도 있습니다.
- 새 판이 있으면 대화 화면 위에 바뀐 점과 '업데이트 하기' 단추가 나옵니다.
- 누르면 받아서 **서명과 sha256 을 확인**한 뒤, 김비서를 잠깐 끄고 프로그램 코드만 바꾸고 다시 켭니다.
  대화 기억·설정·열쇠·목소리·펫 옷·모델은 그대로 둡니다.
- 새 판이 켜지지 않으면 **예전 판으로 저절로 되돌립니다**.
- 파이썬 부품이나 모델이 바뀌는 판은 새 설치 파일로 설치하라고 안내합니다(설치해도 대화 기억·설정은 남습니다).
